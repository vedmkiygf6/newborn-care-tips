# 技术帮扶惠民生｜秦祖杰团队走进龙州开展 “名中医八桂行” 活动

> 更新时间：2026-09-16 (UTC+8)

7月31日至8月1日，秦祖杰团队赴龙州县中医医院开展“名中医八桂行”活动。团队专家通过临床技术指导、带教查房、学术讲座和义诊服务等多种形式，为当地医院提供全方位的技术指导，受到医护人员和群众的欢迎。

▲病例讨论现场

本次活动，龙州县中医医院多名医者受到了国壮专家的“授人以渔”。临床技术指导环节，国壮风湿病科主任李凤珍现场示范了壮医药物竹罐疗法的操作技巧。她不仅纠正了基层医护人员在温度控制和吸附时间把握上的问题，还规范了竹罐的选择标准。“原来拔罐时，轻轻旋转竹罐可以让竹罐与皮肤多接触，就能快速吸附；选竹罐不能太薄也不能太厚……”龙州县中医医院护士梁春艳欣喜地表示，自己又学到了“几招”。

▲李凤珍示范壮医药物竹罐疗法

带教查房环节，龙州县中医医院康复壮医科主任覃安福对壮医水蛭疗法有了更进一步的认识。“不一定非要在肿痛部位施治,可以选择近心端肿痛部位。”覃安福说。

▲专家团队指导壮医水蛭疗法在临床中的应用

骨三科（创伤骨科）主任刘明伟重点指导了当地医院骨伤科的骨折治疗技术，现场讲解石膏固定和绷带包扎等关键技术规范操作的重要性。“绷带包扎也很重要，这代表着一个科室的诊疗水平。”刘明伟在与科室医护团队交流时表示。

▲刘明伟指导绷带包扎技术

期间，国壮专家团队还举办了学术讲座和惠民义诊活动。在延续前两次技术指导内容的基础上，本次新增了科研能力培训。国壮科技部主任杨增艳系统讲解了科研课题的选题、申报和标书撰写等内容，为基层医务人员提升科研水平提供了专业指导。
