# 以为是上火，没想到是舌癌！从发现到确诊仅仅1个月

> 更新时间：2026-09-17 (UTC+8)

舌头上长了一个不痛不痒的肿块，短短1个多月疯长到直径1cm，最终确诊为舌癌，这一不幸落在了曾经罹患多种疾病的老李（化名）身上。

以为是上火，一查竟是舌癌

老李本以为能在家享受天伦之乐，没想到却成了医院的常客。先后因罹患鼻咽癌、胆囊结石伴慢性胆囊炎、慢性肾功能不全等，经历数次住院治疗，身体状况大不如前，人也变得恹恹的。

2个月前，他突然发现舌头上鼓起一个“小包”，他抱着侥幸心理，觉得只是上火了，过几天就能好。没想到经过短短一个月，起初不痛不痒的肿块越长越大，吞咽时伴随明显疼痛。老李说话、吃饭时出现的异样引起了家人的注意，他们这才知道老李舌头上长了一个大肿块，于是赶紧带老李到医院就诊。

经过初步检查后，医生建议老李马上接受活检，进一步明确病因。病理结果出来后，老李一家都懵了。老李舌头上的肿块，是又一原发恶性肿瘤——舌癌，肿块最大直径达1厘米。幸好老李在阳江市人民医院口腔科住院治疗，完善相关检查后，医生为其进行了“右舌癌根治术+下肢胫后动脉穿支皮瓣修复”，现已痊愈出院。

1月接诊3例，舌癌与这些习惯有关

仅最近一个月，阳江市人民医院口腔科就连续收到了3例类似老李的病例。47岁的许先生（化名）近半年多来一直感到舌头疼痛，直到影响进食和说话才来就诊。还有一位卢女士（化名），她也有反复的口腔溃疡病史，这次舌痛1个月不见好转，最终也确诊为舌癌。

据了解，大部分舌癌患者的发病原因都和生活方式有一定的关系，包括以下方面：

1. 辛辣刺激性的食物吃得多；

2. 烟酒刺激；

3. 咀嚼槟榔；

4. 喜欢吃较烫的食物；

5. 不良刺激物，比如口内残留的牙根牙冠；

6. 不注意口腔卫生，滋生大量细菌或者霉菌。 

口腔溃疡超2周不愈要当心

对于大多数人来说，口腔溃疡是常见的事。但是，口腔溃疡超过2周不愈，就要警惕是不是癌症信号。

临床上常见的口腔癌根据发生部位的不同，分为舌癌、牙龈癌、颊黏膜癌、腭癌、口底癌等。其中舌癌大多发生在舌侧缘，也可发生在舌尖、舌背，大多表现为溃疡型，这也就是为什么很多病人会不太重视，以为就是一般的口腔溃疡，用点治疗溃疡的药，如某些含片等，从而耽误了病情。

此外，如果出现言语不清、张口受限、吞咽疼痛、舌固定、牙齿疼痛松动、颈部摸到一些相对固定的肿大淋巴结等，也要提高警惕，尽早就医，明确诊断，评估病情，千万不要存在侥幸心理。

如果口腔溃疡超过2周还没有痊愈，就要去医院找专科医生辨别。

区分口腔溃疡还是口腔癌看4点

初步分辨普通的口腔溃疡与口腔癌，可以看以下4点：

1. 看大小：普通口腔溃疡很小，一般2-3毫米，很少超过5毫米；而癌性溃疡通常大于1-2厘米。

2. 看疼不疼：普通口腔溃疡很疼，通常让人吃不下睡不安；而癌性溃疡通常不痛，等到痛时一般都长到很大，或是晚期了。

3. 看质感：普通的口腔溃疡，摸上去很软；而癌性溃疡摸上去硬硬的，而且溃疡上一般会有凸起，很不光滑。

4. 看周期：普通的口腔溃疡7-10天，就算不治疗一般可自愈。如果还要长，它会换一个地方长。而癌性溃疡会扎根，不会乱跑，也不会自愈。

预防口腔癌，注意4点

1. 养成良好的饮食习惯

首先要养成良好的生活和饮食习惯，戒烟、限酒，饮食忌过烫，减少烟熏、油炸和刺激性强的食物。

2. 保持口腔清洁卫生

注意口腔的清洁卫生，每天早、晚都要刷牙，进食后要及时漱口，养成良好的口腔卫生习惯，及时处理口腔相关疾病。及时处理龋齿，拔除牙的残根和残冠，对于佩戴假牙的人，纠正不合适的假牙，避免牙齿对舌部的不良刺激。

3. 合理膳食

注意饮食营养均衡，饮食以高蛋白、高维生素、清淡、易消化为主。

4. 及时治疗癌前病变

一般认为，黏膜白斑、红斑、黏膜下纤维化等均为癌前病变，如果出现上述病变，一定要及时治疗。

最后，还要注意识别身体出现的异常症状，如果症状持续时间过长、症状进行性加重或是出现其他相关症状，则要提高警惕，及时就医。
